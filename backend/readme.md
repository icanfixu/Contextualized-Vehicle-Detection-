# Backend readme
This readme file is about configure the backend
### Info:
- This project uses python 3.14.3
- See python version: ```python --version``` or ```python3 --version```


# Setup info
- Go to backend folder
- Create the environemnt :  ```python -m venv .venv```
- Active the environemnt:
    - Windows(Command Prompt): ```.venv\Scripts\activate```
    - Windows(Powershell): ```.\.venv\Scripts\Activate.ps1```
    - Linux/mac: ```source .venv/bin/activate```
- Install all the dependencies: ```pip install -r requirements.txt```


# Run the app
- Windows: ```python app/app.py```
- Linux/macos: ```python3 app/app.py```
